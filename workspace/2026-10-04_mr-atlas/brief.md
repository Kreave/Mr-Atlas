# Mr Atlas

Mr Atlas is a rebuild of the Mr. Mak workspace. It is not a game or game-related
workspace. The goal is a work powerhouse that can build anything using
work-related programs, for example Excel.

## What is decided

- **Name:** Mr Atlas, used everywhere in place of Mr. Mak.
- **Direction:** general-purpose work, not game development.
- **Starting programs:** Excel, Word, PowerPoint, PDF and Google Workspace.
- **Skills:** a new skill set built for this workspace.
- **Base:** this repository, cloned from `Kreave/Mr-Atlas`.

## Owner's answers

1. **Which work programs matter first?** Excel, Word, PowerPoint, PDF and Google
   Workspace are a good start. Others can be added later.
2. **What should it build first?** Not decided. This will be chosen later.
3. **Which game skills should be removed or replaced?** Build a new skill set for
   this workspace. The game-oriented skills in `.agents/skills/` are to be
   replaced. Nothing has been removed yet.
4. **Keep the name "Mr. Mak" in window titles and installer?** No. Rename
   everything to Mr Atlas.
